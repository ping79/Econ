核心研究專題

專題一

物價與勞動市場

通膨壓力、實質薪資與青年就業分析

探討 CPI 年增率衝擊下，對受僱員工實質薪資之傳導機制，並實證評估高物價與房價壓力對青年勞動參與率的非線性影響。

專題二

產業與出口結構

半導體出口衝擊與產業薪資雙軌化

聚焦 AI 晶片出口熱潮，檢驗電子零組件出口成長對台灣製造業與服務業薪資差距之溢出效應（Spillover Effect）。

專題三

貨幣與金融市場

貨幣總計數 (M1B/M2) 與資產價格

運用 VAR 向量自迴歸模型，分析台灣貨幣黃金交叉現象對房價指數與股市波動的長短期動態影響。
